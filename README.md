# Under-The-High-Wall

使用 Unity 6000.3.28f1 打开 `Under The High Wall` 项目目录，打开
`Assets/Scenes/SampleScene.unity`，点击 Play 运行救援 Demo。

地图采用约 45° 斜俯视的 3D 棋盘。点击 **Roll d6** 掷骰，再用鼠标点击高亮的相邻地块移动。遇到怪物时点击 **Attack**，
胜利后获得一张回忆卡。找到女孩后带她回到 **Entrance**。回程中女孩受到
袭击时，使用 **Use Memory Card** 降低她的污染。点击 **Restart** 可以重开。
