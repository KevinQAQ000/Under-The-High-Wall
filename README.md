# 高墙之下

使用 Unity 6000.3.28f1 打开 Under The High Wall，打开 Assets/Scenes/SampleScene.unity，点击 Play。

## Demo v0.2（结合作品集桌游与《吉星派对》的骰子对抗）

参考作品集 12–16 页（6 张身份卡、28 张道具四轴、15 种怪物能力、回忆卡）与《吉星派对》（Astral Party）的“双方掷骰 + 手牌加值”战斗，把初版 Demo 从固定伤害改成骰子对抗。

- 8×7 桌游卡牌地图（横向 8 格、纵向 7 格，最下面一排已去掉），按用户实物参考平铺大小方形卡牌，使用作品集 Venue 卡背，卡间留白。大小卡目前都按一个逻辑格计算。
- 开局从六张身份牌里随机抽两张不同的身份，两名角色各一张；先播放滚动抽牌动画，点“继续”进入棋盘。
- 两名角色由同一玩家轮流控制，点“结束回合 / 切换队友”交接；开局双方各掷一个骰子定先后，同点重掷。
- 掷骰后逐格点击高亮节点，步数耗尽才翻开落点。
- 每局开局都重排棋盘事件：四只怪物的种类和位置随机、女孩位置随机、教室/医务室/陷阱也随机，墙和通道保持固定；怪物离入口至少 3 步、女孩至少 5 步。接女孩后重洗时，没被打败的怪物会保留种类重新摆放。
- 离女孩还有 1 格时提示“哭声就在隔壁”，2 格“隐约听见女孩在哭”，3 格“远处传来细微的哭声”。地块：教室抽道具卡、医务室降污染、陷阱加污染、怪物 1–4、入口、女孩。
- 手牌上限 4 张，分为攻击（攻击 +N）、护盾（护盾 +N）、净化（污染 -N）。攻击与护盾卡只在战斗里生效，净化卡随时可用；落点抽卡与击败怪物都会补牌。
- 战斗改为掷骰对抗：攻击 = 你 1d6 + 攻击力 2 + 手牌，对怪物 1d6 + 怪物攻击力；点数高者压制，差值造成伤害或污染。防守 = 你 1d6 + 护盾，对怪物 1d6，成功格挡并反击 1 点。平局僵持，本轮无伤害。
- 队友支援：两格内的队友每场一次，掷一个骰子加到下一次攻击的点数上。
- 撤退：不能绕过怪物——留在原地、污染 +1，下一回合继续面对同一只怪；蜘蛛会缠住你，连撤退都不行。
- 找到女孩后重洗道路事件，保留路网、角色位置与未击败的怪物。携带者受击连带女孩，携带者退场后女孩留在原地等待另一人接应。
- 带女孩落在入口通关；两人都退场或女孩污染满则失败。
- 地图、角色、UI、按钮事件和素材均预先保存到场景。手牌栏与战斗手牌槽由菜单“高墙之下 / 生成 Demo v0.2 界面”生成（Assets/Editor/DemoV02Setup.cs）；身份栏、技能按钮与抽牌面板由菜单“高墙之下 / 生成身份牌界面”生成（Assets/Editor/DemoIdentitySetup.cs）；整体 HUD 布局由菜单“高墙之下 / 生成战斗 HUD 布局”生成（Assets/Editor/DemoHudSetup.cs）。

## 单文件网页版

生成脚本会把整个 WebGL 构建（data / wasm / framework 各 gzip 后 base64 内嵌）打包成**单个约 42 MB 的 HTML**，可以直接双击、也可以发给别人双击打开（Chrome / Edge）。仓库里不保留构建产物，需要时按下面的步骤重新生成。

- 生成脚本：`_analysis/make_single_html.py`（需要先跑过“高墙之下 / 导出 WebGL”）。
- 首次打开会在页面上显示“正在解压游戏资源…”，解压完自动进主菜单；加载耗时会写进页面标题。
- 浏览器需要支持 `DecompressionStream`（Chrome 80+ / Edge 80+）。
- 如果双击打不开，退回文件夹版：`Builds/WebGL/index.html` 必须由本地服务器提供（`python -m http.server 8090` → http://127.0.0.1:8090/）。

## 网页版（WebGL）

- 菜单 **高墙之下 / 导出 WebGL**（`Assets/Editor/DemoWebGLBuild.cs`）把工程导出到 `Builds/WebGL`。
- 导出后必须用本地服务器打开，直接双击 `index.html` 会被浏览器的安全策略拦住：
  在 `Builds/WebGL` 目录执行 `python -m http.server 8090`，再访问 `http://127.0.0.1:8090/`。
- 导出时关闭了 Brotli 压缩（本地静态服务器不带压缩响应头），所以文件夹约 73 MB，首屏加载需要等一会儿。
- 网页版里棋盘、棋子、底座必须用 URP/Unlit 材质（菜单“高墙之下 / 修复网页版材质”，`Assets/Editor/DemoWebMaterials.cs`）：URP Lit 在 WebGL 里会渲染成纯黑，柱子和棋子会消失。这个菜单只改 scene 里的一批材质引用，导出完记得把场景改回来（编辑器里改用 Lit 才有光影效果）。

## 界面布局

参考《吉星派对》的战场式界面，3D 棋盘铺满全屏，HUD 浮在上面：

- 左上角：两名角色的头像、身份名与各自污染值，当前行动者的头像亮起并套一圈橘黄色边框，队友压暗。边框由菜单“高墙之下 / 生成行动高亮框”（Assets/Editor/DemoActiveFrame.cs）生成。
- 右上角：骰子、余步、女孩污染、回忆卡、手牌数量。
- 底部中间：当前手牌，四张竖卡。卡面用作品集第 15 页裁出的道具图，下方中文条显示名称与数值；攻击卡红色、护盾卡蓝色、净化卡绿色、空槽灰色。
- 右下角：投掷骰子、技能、使用回忆卡、结束回合 / 切换队友、重新开始。
- 左侧头像下方是引导面板：目标、事件消息和新手引导。引导按局面自动推进四步——掷骰子、走格子、战斗出牌、护送女孩回入口。面板半透明、约 210×168，和头像一起贴着屏幕左边；抽身份时不显示，点“继续”进入棋盘后才出现。由菜单“高墙之下 / 生成新手引导”（Assets/Editor/DemoGuideSetup.cs）生成。
- 手牌标题只写“手牌”，操作说明统一放在左侧引导面板里。
- 鼠标停在按钮或手牌上时不会触发棋盘移动（EventSystem 拦截）。
- 抽到新牌时卡槽横向展开，做出翻牌效果；点“结束回合”换人时镜头先拉远看全景，再回到当前角色。
- 贴图统一取自 Assets/Art/card：身份卡 6 张、怪物卡 4 张、道具卡 5 张、卡背用 Venue 卡背。由菜单“高墙之下 / 替换正式素材”接回场景（Assets/Editor/DemoAssetSwap.cs），手牌槽由“生成卡面与台子”生成（Assets/Editor/DemoCardSetup.cs）。

## 身份牌

开局随机两张，技能次数用完即止；室友与挚友的技能每场战斗刷新一次。

| 身份 | 技能 | 效果 |
| --- | --- | --- |
| 室友 | 可分享的护盾 | 本场战斗护盾 +4 |
| 老师 | 开局的准备 | 多抽 2 张道具卡 |
| 保安 | 钥匙串 | 抽 1 张道具卡，并免疫一次陷阱 |
| 妈妈 | 闪避 | 接下来两次污染免疫 |
| 医生 | 消除感染 | 自己与队友污染各 -2 |
| 挚友 | 阻止攻击 | 本场战斗怪物攻击 -3 |

- 素材说明：卡面原图是非 2 次幂尺寸（732×1028），Unity 默认缩到 512×1024 会把人像压长；已用菜单“高墙之下 / 修复素材比例与封面”把导入设置改为不缩放（NPOT = None），并在同一菜单里重挂封面 Logo 与三张展示卡。
每张牌下面是一根 0.9 高的柱子（底面贴地、顶面 0.84），牌立在柱顶，角色和女孩站在牌上；镜头取景会把这段高度算进去，避免上方两排被裁掉。
第三只怪是“双面人”，对应 Two-Faced 的卡面；棋盘改动由菜单“高墙之下 / 去掉最后一排”（Assets/Editor/DemoBoardSetup.cs）完成。
怪物血量、攻击力、伤害、支援距离及污染上限属于 Demo 测试数值。角色与建筑仍使用占位模型，尚未实现卡内多格与联网。

镜头在待机和回合结束时展示全图，掷骰移动或战斗时聚焦当前角色并平滑跟随。可在 RescueDemo Inspector 调整聚焦尺寸和跟随速度。
